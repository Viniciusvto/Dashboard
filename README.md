# Painel de Checklists GBMX

Painel que mostra os checklists de segurança do Guincho Tracionador 1172.
Os dados são baixados automaticamente do GitHub a cada 30 segundos.

## Como usar

1. Instalar o [Python](https://www.python.org/downloads/) (nenhuma biblioteca extra é necessária).
2. Executar:
   ```
   python painel_checklists.py
   ```

- **F11**: entra/sai da tela cheia (para uso em televisor).
- Sem internet, o painel mostra os últimos dados baixados.
